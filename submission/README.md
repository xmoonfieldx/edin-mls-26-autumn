See [`asr/ASR_README.md`](asr/ASR_README.md) for the five submitted CUDA source files, GPU test instructions, model profiling command, and saved ASR outputs.

## 2. RAG retrieval and reranking

See [`rag/RAG_README.md`](rag/RAG_README.md) for prerequisites, experiment commands, transcript-cache controls, diagnostics, and result-comparison instructions.

## 3. Report and video

Submit the final report and video using the course's required submission routes. The report should describe the methods and results documented in the ASR and RAG guides.

## 4. General notes

The ASR and RAG components use separate environments and have separate reproduction steps. Follow the relevant component guide from the course repository. Credentials, downloaded model weights, course data assets, and local Python environments are not included in this submission folder.
